## One library.Wherever you build.

Connect your agent. Give your AI agent access to Alexandria through MCP or the CLI.

```bash
npx -y firecrawl-cli@latest init --all --browser
```

[View the docs](https://docs.firecrawl.dev/ai-onboarding)

Build it into your app. Find tools alongside the web with the API and SDKs.

```javascript
const result = await firecrawl.search(
  "podcast conversations about AI agents",
  {
    sources: ["web", "alexandria"],
    limit: 2,
  },
);

// Pages to read. Tools to go further.
console.log(result.web);
console.log(result.tools);
```

[View the docs](https://docs.firecrawl.dev/features/search)
