## The fastest way to build internal agents and AI systems

Keystroke gives teams everything they need to build extremely powerful agents and AI systems, all in a single platform.

[Get started](https://keystroke.ai/signup)

## What Keystroke handles for you

### Build agents that do real work

Build powerful agents with built-in memory, a persistent file system, integrations, tools, and more.

- #### 300+ models
	Use 300+ supported models, or bring your own API keys.
- #### Built-in memory
	Ship agents with built-in memory and across conversations.
- #### Persistent workspace
	Equip agents with a file system, code execution, and isolated VM.
- #### Persistent browser
	Give agents a browser that stays signed in across runs.
- #### Web search
	Agents can search and navigate the internet with native web tools.
- #### Use from anywhere
	Use agents via our chat interface, API, or in platforms like Slack.
- #### Powerful tools
	Assign workflows, subagents, and more as robust tools.
- #### Self-scheduled triggers
	Ask agents to set their own triggers and schedule their own tasks.

### Observability & governance

Empower teams to build their own agents, while maintaining security, governance, and visibility.

- Test and audit every agent
- Full visibility across teams
- Usage limits and guardrails

- #### Org-wide visibility
	Understand which teams, agents, models, and tools are being used.
- #### Usage limits
	Set budgets, rate limits, and usage policies across teams and projects.
- #### Model controls
	Define approved models, providers, and data requirements.
- #### Tool permissions
	Control which users can access sensitive tools and integrations.
- #### Role-based permissions
	Set role-based permissions across tools, integrations, and more.
- #### Safety policies
	Require approvals and block high-risk actions before they occur.
- #### Alerts and audit trails
	Detect unusual behavior and maintain a complete record of every action.

## Every agent you build is real code you own

No black boxes. No platform lock-in.

Everything you build in Keystroke is defined in plain TypeScript. Keep your code in git, review every change, and run it anywhere.
