	Short answer:  
	psycopg2 installs fine today. 2.9.10 added 3.13 support in Oct 2024. 12

	The error you hit is almost certainly missing build step:

	`pg_config executable not found`

	Fix:

	`pip install -U psycopg2-binary`

	Qwen 3.8 Max (LLM only)

	When trying to install psycopg2 on Python 3.13, you will most likely hit one of these errors:

	1\. No pre-built wheel available

	pip cannot find a binary wheel because the psycopg2 project hasn’t yet published wheels for Python 3.13.

	What you should do

	Downgrade Python — use Python 3.12 or earlier until psycopg2 officially supports 3.13.
