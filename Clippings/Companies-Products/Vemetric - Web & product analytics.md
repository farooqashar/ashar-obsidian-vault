### User journeys

Track the full path a user takes, merge their anonymous and logged-in activity, and uncover decisive moments.

Save individual data for each user and see how and via which devices they interact with your product.

- Events grouped by days and sessions
- All user data at a glance
- Interactive Activity Heatmap
[Learn more](https://vemetric.com/docs/product-analytics/user-journeys)

### Funnels

Track the conversion rate through a series of events, helping you understand where users drop off.

You're able to map each step of your funnel to a specific pageview or event, to get a better understanding how users progress through your product.

- Powerful filtering (see how different user segments convert)
- Integrated on the Dashboard
- View the Funnel Progress of individual Users
[Learn more](https://vemetric.com/docs/product-analytics/funnels)

## Frequently Asked Questions

If you have any additional questions, please don't hesitate to contact us.

### What kind of Analytics does Vemetric provide?

Vemetric provides you with Web- and Product Analytics. Doesn't matter if you're running a simple website or a more complex product like a SaaS, Vemetric has you covered and you don't need another tracking solution in your toolbelt.

To see what's possible, check out our Docs for the [Dashboard](https://vemetric.com/docs/dashboard) and [User Journeys](https://vemetric.com/docs/product-analytics/user-journeys). I'm planning to add more features like Funnels and more in the future, if you have any suggestions, please let me know!

### Is the event limit per project?

In Vemetric you'll create an Organization and can add multiple projects to it. The event limit counts across all the projects in your Organization.

On the free plan you have 2 projects included and on our paid plans you're able to add unlimited projects to your Organization.

### What if I exceed the event limit?

We'll continue to track all events even if you exceed the limit. However, you won't be able to access your dashboard if you exceed the limit multiple times, so please make sure to upgrade your plan in time.

If you exceed the event limit due to a DDoS attack please get in touch, we won't charge you for overage events.

### Is Vemetric Open Source?

Yes, Vemetric is open source and licensed under the AGPLv3 license. You can find the code on [GitHub](https://github.com/vemetric/vemetric). Checkout the [announcement post](https://vemetric.com/blog/vemetric-going-open-source) to learn more about it.

In case you want to contribute, please check our [Contribution Guidelines](https://github.com/vemetric/vemetric/blob/main/CONTRIBUTING.md).

### Does Vemetric use Cookies?

By default Vemetric doesn't use any kind of Cookies and all our servers are hosted in the EU. Vemetric is therefore GDPR compliant. For identifying recurring visitors on the same day, we generate a unique hash for each of your visitors with a daily rotating salt.

With that said, Vemetric also supports using Cookies as an opt-in. We'll publish detailed Docs and Guidelines on how and when you might want to consider using Cookies for tracking your users.

### Can I self-host Vemetric?

Not yet, but I'm working on a Community Edition that will be a self-hostable version of Vemetric and include all core features for free.

Stay tuned for more updates!
