## SYNOPSIS

**Review is an open-source desktop app designed to give you confidence in your code.**

Critique interactive visualizations, diffs, and agent trajectories, all from one interface.

## FEATURES

Hover a row to explore an example on the right

Review diffs at the architecture level: sequence diagrams, DB diagrams, and more!

Interact inline with a snapshot of the authoring agent.

Understand if the decisions you made were completed correctly, and if the decisions the agent made make sense.
