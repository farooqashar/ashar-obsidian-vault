Abstracted cards with API key representations for Anthropic and Open AI

You can now bring your own key to Linear’s cloud coding agent and use your existing provider credits and negotiated rates.

Connect through OpenAI, Anthropic, AWS Bedrock, Azure OpenAI, Claude in Microsoft Foundry, OpenRouter, Vercel, or any gateway that supports the OpenAI Responses or Anthropic Messages API.

Your provider bills model usage directly, while sandbox runtime uses Linear AI credits. You’ll need an API key, not a ChatGPT or Claude subscription.

Workspace admins can enable BYOK in [Settings](https://linear.app/settings/ai/coding-sessions). Available on all current plans. Learn more in our [documentation](https://linear.app/docs/coding-sessions).
