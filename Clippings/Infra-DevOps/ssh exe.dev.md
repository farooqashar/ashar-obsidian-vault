## API first

`ssh exe.dev` to see for yourself.

exe.dev

$ ssh exe.dev exe.dev ▶ new --name my-openclaw --prompt "Install OpenClaw 🦞. exe.dev handles auth"

A built-in web agent to build apps.

### It’s just a computer

You buy a pool of CPU, RAM, and disk. You get as many VMs as you like.

SSH in, you are root, you have `apt` and `systemd`. Your servers are persistent, private by default, and shareable with [IAM](https://exe.dev/docs/proxy).

You have a web agent too, [Shelley](https://exe.dev/docs/shelley/intro), for coding.
