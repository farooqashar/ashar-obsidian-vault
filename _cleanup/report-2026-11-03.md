**Trash retirement is now actually reachable.** The reason it wasn't in recent weeks was that `device_bash`'s `~` is a throwaway VM home, not your Mac's. This script runs as you, on your Mac, so `~/.Trash` is the real one. It is **off by default** — the plain command above moves nothing out of the vault. If you want the three byte-identical copies retired:

```bash
RETIRE_DUPES=1 ./apply-2026-11-03.sh
```

That re-runs `shasum -a 256` on each pair at run time and skips any pair that is no longer identical, so it cannot act on stale information. Files go to `~/.Trash` with a timestamp prefix and the relative path flattened, so you can put any of them back. It covers only `Braindate 1`, `TinyFish 1` and `Requests, Please … 1` — never the `ssh exe.dev` or `FreeHire` pairs, which are not identical. Both halves of each identical pair have different basenames, so no `[[wikilink]]` is ambiguous while they sit there.
